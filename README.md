# Nexora Bio

A modern biotechnology landing page built with HTML, CSS, and JavaScript.

## About

Nexora Bio is a fictional biotechnology website focused on precision biology,
computational biology, molecular engineering, and AI-driven discovery.

## Features

- Responsive design
- Modern biotechnology-themed UI
- Animated hero section
- DNA-inspired visual animation
- Smooth scrolling navigation
- Mobile navigation menu
- Scroll reveal animations
- Interactive cards
- Animated statistics
- Mouse-follow glow effect
- Back-to-top button

## Technologies Used

- HTML5
- CSS3
- JavaScript
